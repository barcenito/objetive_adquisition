# Recursos de hardware

- `esquema_a121.png`: esquema del sensor A121.
- `Acconeer_A121_sensor_Altium_Libv/`: bibliotecas originales de Altium.
- `prueba1/`: configuración inicial de un proyecto Eclipse/STM32CubeIDE;
  no contiene firmware de aplicación. La configuración `.cproject` conserva
  la ruta original del compilador y debe ajustarse al equipo antes de utilizarla.

Estos recursos se conservan como referencia y no intervienen en la ejecución
del simulador Python. El SDK del fabricante está en `../vendor/acconeer_sdk/`.
